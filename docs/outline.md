# 《致命游戏》第一扇门（雪村）剧情梳理 —— 改编用

## 0. 书名选择说明

以“致命游戏”为名的作品不止一部，检索时查到的有：

| 作品 | 作者 / 平台 | 说明 |
|---|---|---|
| 《死亡万花筒》（改编网剧名《致命游戏》，2024，爱奇艺） | 西子绪 / 晋江文学城 | 无限流灵异悬疑、双男主；网剧上线不到两小时就下架，之后靠网盘流传、影响很大。“致命游戏”这个名字现在最常让人联想到的就是这部 |
| 《致命游戏：全能大佬搞钱攻略》 | 妖无辜 / 晋江 | 女主林西，团队副本无限流，连载很长（1000 多章）；第一个副本是“百花酒店” |
| 《致命游戏》 | 山阳 / 晋江 | 约 9.7 万字的短篇纯爱，冷门 |
| 《致命游戏（无限流）》 | 叶淮南依 / 长佩 | 约 9.8 万字，没写完，冷门 |
| 《致命游戏》 | 雪漫迷城 / 2013 年出版 | 实体悬疑小说 |

**选了《死亡万花筒》**，也就是网剧《致命游戏》的原著。理由：在同名作品里知名度最高；是“游戏化”的无限流惊悚题材；有两位主角，人物关系明确，正好对应“主角之间的信任值”机制。游戏标题沿用《致命游戏》，人物用**原著名字**（林秋石 / 阮南烛）。网剧里两人改名为凌久时 / 阮澜烛，这一点写进了人物档案。
如果想做的其实是妖无辜那本，需要另外改编，这份大纲用不上。

## 1. 作者与平台
- 作者：西子绪；首发晋江文学城（已完结，出过实体书，第一册收录第 1–4 扇门）。
- 网剧：《致命游戏》，2024 年 2 月 2 日在爱奇艺上线，夏之光饰阮澜烛，黄俊捷饰凌久时。

## 2. 世界观（门的规则）
- 只有濒死的人才会“被门选中”。进门前会有预兆，比如家里的猫突然不让抱了。随手推开一扇普通的门，看到的就会是**挂着十二扇铁门的走廊**。
- 进门后要根据门内人物给的线索**找到钥匙**，再**找到那扇铁门**，开门才能出去。拿钥匙开门的人会得到一张写着下一扇门线索的纸条。
- 门里死了，回到现实也会死；门里受伤，现实中会生病。门里待好几天，现实只过去几分钟。过完全部十二扇门，就能获得新生。
- 进同一扇门的人里，至少会有一个活着出去；只剩最后一个人时，这个人处于无敌状态。在门里杀人会遭到报复（死者得知道是谁杀了自己）。
- 鬼怪一般“守规矩”，不会乱杀人；高难度的门例外。

## 3. 主要人物
- **林秋石**：新人，重病（来源说法不一，见第 6 节），养了一只猫叫栗子。冷静，心理素质好，有底线，嘴上偶尔吐槽，人很温和。
- **阮南烛**：黑曜石（专门带人过门的组织）的老大。第一扇门里穿女装，自称“阮白洁”：个子很高，柔弱是装的，嘤嘤嘤也是装的，胆子极大，动不动怼 NPC，喜欢逗林秋石。门外的真身是个漂亮但气场压人的男人。
- **熊漆**：老手，自然成了这一队的领头人，冷静务实。
- **小柯**：老手，女性，表面淡定，其实也到了崩溃边缘（找到钥匙时喜极而泣）。
- **程文**：队里的老手，第一天就心态崩了；后来被林秋石打晕。
- **王潇依**：同队成员，后来夜里死了。
- **村长**：穿军绿棉袄、提油灯的中年人，委托大家“造一口棺材”。
- **木匠**：住在村东头的老人，交代造棺材的流程。
- 同队一共 13 人（九男四女）。

## 4. 第一扇门：雪村（按事件顺序）
1. **预兆与走廊**：猫栗子不让林秋石抱了；他推开家门，眼前是挂着十二扇铁门的走廊，推开第一扇。
2. **雪林与村子**：进门后只有一条路穿过茂密的雪林，通到村子；村子也只有一条路通往山林。正值严冬，下着雪。路上遇到穿长裙的“阮白洁”，两人互通姓名。（她嫌林秋石矮，“一米八还没我高”这类梗，游戏里另写了台词。）
3. **住处**：熊漆把大家接到一栋三层木楼。13 人，九男四女。
4. **第一夜**：夜里出了怪事，两人“跑得飞快”。第二天早上，**三楼死了两个人**，血肉模糊，像被剥了皮；地上大片血已经冻住。林秋石的**头发里全是冻住的血渣**，抬头看，三楼**天花板上有东西爬过的血痕**。他在二楼听见三楼有女人哭，别人都说没听到。
5. **村民与井**：村民做早饭，说一下雪山路就封死了。林秋石问起“井”，村民神色紧张。
6. **村长委托**：村长来了，说村里想造一口棺材，请大家给木匠帮忙。他一走，门被风砸碎了。程文崩溃。熊漆判断：钥匙就是棺材。
7. **木匠**：熊漆、小柯、林秋石、阮白洁去村东头找木匠。木匠说：先砍树，木料送来，再去**庙里拜一拜**（造棺材损阴德）。问拜完以后呢，他不说。阮白洁抄起木棍作势要动手，木匠才说：**拜完再去填一口井，棺材就好了**。
8. **规则提示**：这扇门的线索纸条是“**一人不入庙，二人不观井，三人不抱树，独自莫凭栏**”。
9. **背景**：村里供奉着一尊神，是个**长发女人，拿斧头，脖子能伸得极长**。她是邪神，保佑村子平安，却喜食生骨肉。村民每年冬天用活牲祭祀，今年牲畜全死了，于是**外来的人成了“活牲”**。
10. **任务流程**：砍树 → 木料送木匠 → 拜庙 → 拜完后**三天内**用**死物（需要死人）**填井 → 去木匠那里取棺材；顺序不对就得从头再来。
11. **填井之夜**：大家在院子里坐了一夜，围墙外那个女人一直盯着他们；**咀嚼声**响了一整夜，天快亮时才停，女人也消失了。**王潇依**死在外面，第二天原地什么都没留下。
12. **取棺**：木匠家里立着一口**漂亮的红棺材**，漆是**血浸**的，腥，滑；抬起来却**轻飘飘的**，两个人就扛得动。林秋石和熊漆把它抬回去。
13. **钥匙**：开棺后小柯找到一把**陈旧的青铜钥匙，把手上沾着血**。阮白洁认为拿钥匙的人死得快，熊漆让林秋石保管。
14. **门**：**铁门在井里**，林秋石用钥匙开了门。
15. **出门之后**：林秋石发现**右耳**被阮白洁偷偷扎了个**耳钉**；他捡到的纸条上写着“**菲尔夏鸟**”（第二扇门的线索）。不久，一个陌生的漂亮男人夜里出现在他家，自称**阮南烛**，带他进了黑曜石。

## 6. 存疑之处与处理
- **病名**：一处来源写肺癌晚期，另一处写肝癌晚期。游戏里只说“重病”和“医生给的那个数字”，不写具体病名。
- **线索纸条在谁手里**：没有可靠来源。游戏只写“这扇门给的提示”，不写是谁带进来的。
- **第一夜具体发生了什么**（只知道两人逃跑，三楼死了两人）：游戏里写成敲门声、天花板上的爬行声，具体细节处理得模糊。
- **填井用的是谁**：来源只说“需要死人”“在同伴死亡与填井之间抉择”。游戏写成用**已经死去的同伴遗体**填井（这是改编安排，原文是否如此不确定），并且坚持“不杀活人”的底线；这也呼应原著“在门里杀人会遭报复”的规则。
- **程文为什么被打晕**：原因不详。游戏写成他夜里失控要往外冲，林秋石为了拦他把他打晕。属于合理补写。
- **井里怎么找到门、熊漆和小柯的结局**：细节不详。游戏只写“门在井里”，同伴的结局写得含糊（“活着走出来的人不多”），不点名谁生谁死。
- **规则四句具体怎么触发死亡**：原文细节不详。游戏把四句话做成玩家必须遵守的“规则谜题”，违反就有后果，是对规则的游戏化演绎。
- 所有叙述和对白都是重新写的，没有摘录原文。
